# 🌐 AIoT 智慧控制系統 (ESP32 + Flask + Render)

這是一個結合 ESP32、Python Flask 與雲端平台的智慧控制專題。
可透過網頁輸入「開燈」、「關燈」等指令，控制實體 ESP32 LED。

## 🔧 架構
使用者 → Flask 雲端伺服器 → Wi-Fi TCP → ESP32 → LED

## 🚀 部署步驟
1. Fork 或 clone 此專案到自己的 GitHub。
2. 登入 [Render.com](https://render.com)。
